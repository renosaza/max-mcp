# Инструменты max-mcp

Все временные метки передаются как Unix time в миллисекундах. Идентификаторы чатов и каналов передаются как целые числа. Идентификаторы сообщений в указанных ниже инструментах можно передавать целым числом или десятичной строкой.

## Чтение

### `list_chats(limit=50, marker=None)`

Возвращает список чатов пользователя.

- `limit`: от 1 до 100;
- `marker`: курсор из поля `next_marker` предыдущего ответа.

```json
{
  "chats": [
    {
      "id": 123456789,
      "title": "Рабочий чат",
      "type": "CHAT",
      "last_event_time": 1717520000000,
      "participants_count": 12,
      "description": null,
      "owner_id": 987654321
    }
  ],
  "next_marker": 1717519999999
}
```

Типы чатов обычно представлены значениями `DIALOG`, `CHAT` и `CHANNEL`.

### `get_chat(chat_id)`

Возвращает сведения об одном чате или канале.

### `find_chats(query=None, kind=None, limit=50, max_chats=1000)`

Ищет подстроку без учёта регистра по названию чата, имени профиля и подписи собеседника в контактах. Без `query` возвращает справочник по свежести. `kind` при необходимости ограничивает тип: `DIALOG`, `CHAT` или `CHANNEL`. `limit` — от 1 до 500, `max_chats` — от 1 до 10 000 просмотренных чатов. Точные совпадения идут перед совпадениями по началу и подстроке.

Ответ содержит `chats`, `total_matched`, `directory_truncated` и `unresolved_users`. При `directory_truncated=true` полнота поиска не подтверждена, поэтому отсутствие результата не доказывает отсутствие чата; `total_matched` относится только к просмотренной части. `unresolved_users` — число уникальных собеседников без доступного имени профиля или контакта (для групп и каналов — 0); если оно больше нуля, отсутствие совпадения по имени также не доказывает отсутствие чата.

### `get_user(user_id)`

Возвращает `id`, `name`, `profile_name`, `contact_name`, `description` и `dialog_chat_id` для пользователя. Отсутствующие имена могут быть `null`.

### `read_messages(chat_id, limit=50, before_time=None)`

Читает историю от новых сообщений к старым.

- `limit`: от 1 до 100;
- `before_time`: значение `next_before_time` из предыдущего ответа.

```json
{
  "messages": [
    {
      "id": 116691985249148380,
      "message_id": "116691985249148380",
      "chat_id": 123456789,
      "sender": 5267903,
      "text": "Пример сообщения",
      "time": 1717520000123,
      "type": "USER",
      "reply_to_id": null,
      "reply_to_message_id": null
    }
  ],
  "next_before_time": 1717520000122
}
```

Поля `id` и `reply_to_id` сохранены как числа; их строковые эквиваленты — `message_id` и `reply_to_message_id`, либо `null` при отсутствии идентификатора. Для идентификаторов больше 2⁵³ используйте строковые поля: JavaScript может округлить числовое значение.

Поле `attaches` появляется только у сообщений с вложениями. Его структура зависит от типа вложения. Бинарные поля заменяются строками вида `<N bytes>`; исходные байты в JSON не передаются.

### `search_messages(query, chat_id, limit=50, scan_limit=500)`

Ищет подстроку без учёта регистра, последовательно читая историю выбранного чата.

- `query`: непустая строка;
- `limit`: максимум 100 найденных сообщений;
- `scan_limit`: максимум 10 000 просмотренных сообщений за вызов.

```json
{
  "messages": [],
  "scanned": 500,
  "scan_exhausted": true,
  "history_exhausted": false
}
```

`scan_exhausted=true` означает, что достигнут `scan_limit`, но начало истории ещё не найдено. `history_exhausted=true` означает, что история закончилась.

### `list_channel_posts(channel_id, limit=50, before_time=None)`

Работает как `read_messages`, но сохраняет данные публикаций канала, включая `reaction_info` и `stats`, когда они есть в ответе MAX.

### `dump_channel(channel_id, since_time=None, max_posts=1000, before_time=None)`

Пакетно читает публикации канала.

- `since_time`: не включать публикации старше указанной временной границы;
- `max_posts`: от 1 до 1000;
- `before_time`: курсор для продолжения предыдущей выгрузки.

```json
{
  "posts": [],
  "count": 1000,
  "stopped_reason": "max_posts",
  "next_before_time": 1717510000000
}
```

Варианты `stopped_reason`:

| Значение | Причина остановки |
|---|---|
| `max_posts` | достигнут лимит текущего вызова |
| `since_time` | достигнута временная граница |
| `exhausted` | история канала закончилась |
| `invalid_cursor` | в ответе не нашлось пригодной временной метки |

Для продолжения передайте `next_before_time` в следующий вызов:

```text
dump_channel(channel_id=..., max_posts=1000)
dump_channel(channel_id=..., max_posts=1000, before_time=<next_before_time>)
```

### `list_attachments(chat_id, message_id)`

Принимает `message_id` как целое число или десятичную строку и возвращает его строкой вместе с `attaches`, содержащим индекс `attach_index` для каждого вложения. Индексы начинаются с нуля. Например: `list_attachments(chat_id=123456789, message_id="116691985249148380")`.

### `download_attachment(chat_id, message_id, attach_index=0, dest_dir=None)`

Принимает `message_id` как целое число или десятичную строку и возвращает его строкой. Скачивает FILE, PHOTO, VIDEO или AUDIO и возвращает локальные `path`, `filename`, `size`, тип и идентификаторы; для FILE также проверяется объявленный размер. Внешнее видео без прямой ссылки необходимо открыть в MAX.

Каталог назначения должен существовать, не быть конечной символьной ссылкой и находиться в списке `MAX_MCP_DOWNLOAD_ROOTS` (пути через `:`). По умолчанию используется существующий `~/Downloads`; если указан свой список, используется его первый каталог. Защищённые каталоги запрещены и для значения по умолчанию. Разрешены только HTTPS-адреса `max.ru`, `oneme.ru`, `okcdn.ru`, `mycdn.me` и их поддомены; каждое перенаправление проверяется. Максимальный размер — 2 ГиБ, тайм-аут запроса — 600 секунд. Файл записывается с правами `0600` и публикуется без перезаписи существующего; при ошибке временный файл удаляется. Расширение добавляется при его отсутствии по сигнатуре, MIME-типу или типу вложения.

## Запись

### `send_message(chat_id, text, reply_to_id=None)`

Отправляет непустое текстовое сообщение. `reply_to_id` превращает его в ответ на конкретное сообщение и принимает целое число или десятичную строку, например `reply_to_id="116691985249148380"`.

### `send_file(chat_id, file_path, caption=None)`

Отправляет локальный файл. Тип вложения выбирается по расширению:

| Расширения | Тип |
|---|---|
| `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.bmp` | фото |
| `.mp4`, `.mov`, `.webm` | видео |
| остальные | файл |

Требования к пути:

- файл существует и является обычным файлом;
- конечный компонент пути не является символьной ссылкой;
- размер не превышает 2 ГиБ;
- путь находится в разрешённом каталоге и не попадает в запрещённые системные каталоги.
