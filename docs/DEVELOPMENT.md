# Разработка

## Установка окружения

```bash
uv sync --frozen
```

## Локальные проверки

Проверка синтаксиса:

```bash
uv run python -m compileall -q src tests
```

Линтер без изменения lock-файла:

```bash
uv run --with ruff ruff check src tests
```

Тесты:

```bash
uv run --with pytest pytest -q
```

## Структура

```text
src/max_mcp/
  auth.py          авторизация и защита файлов сессии
  client.py        жизненный цикл PyMax-клиента
  config.py        общий профиль версии MAX и параметры безопасности
  normalize.py     преобразование моделей PyMax в JSON-совместимые словари
  server.py        точка входа FastMCP
  tools/           MCP-инструменты
```

Тесты не используют реальный аккаунт MAX: сетевой клиент заменяется простыми заглушками.

## Правила изменений

- не добавлять токены, номера телефонов и файлы `~/.max-mcp/` в репозиторий;
- сохранять обратную совместимость имён инструментов и основных полей ответов;
- для новых операций записи добавлять явную проверку входных данных;
- для обхода истории всегда предусматривать лимит и курсор продолжения;
- изменения авторизации проверять отдельно для QR и SMS-сценариев.
